使い方

SHARPのポケコンPC-1245・PC-1250・PC-1251・PC-1255・PC-1260・PC-1261・PC-1262・PC-1350のエミュレータです。ブラウザの中だけで動き、ROMは使いません。BASICはROMなしで動くように作り直したもので、未対応の命令もあります。

キーを押す

本体のキーをクリックするか、指で押します。パソコンのキーボードでは、英数字と記号をそのまま打てます。ポケコンにしかないキーは、次のキーで押します。

TabSHIFT
Option(WindowsはAlt)DEF
F1〜F4モードの切り替え

キーの対応の一覧は、⌘/(WindowsはCtrl/)で出ます。機種は、ページの上で切り替えます。PC-1350では、RAMカードもそこで選べます。

プログラムを読み込む

  • 本体の下の「プログラム」から、同梱のプログラムを読み込んで実行できます。
  • 手元の.bas・.hexのファイルは、「ファイルを読み込む」で選ぶか、このページに落とすと読み込みます。読み込んだファイルは「プログラム」の一覧にも残ります。
  • ほかのサイトに置いた.bas・.hex・.wavのファイルは、このページのアドレスに?load=とファイルのURLを付けたリンクで読み込めます。&runも付けると、実行まで進みます(.wavはCLOADしてRUN)。読み込めるのは、ほかのサイトからの読み込みを許しているサイト(GitHubなど)に置いたファイルだけです。
  • 「プログラム」の「プログラムをリンクにしてコピー」で、RAMにあるBASICのプログラムをそのまま入れたリンクができます。リンクを開くと、そのプログラムを読み込んで実行します。
  • マシン語は、本体の下の「作業欄」で書いて実行できます。

全画面で表示する

「全画面」を押すと、ページの上の欄と本体の下の操作欄を隠し、本体だけを画面いっぱいに出します。全画面表示に対応しているブラウザでは、ブラウザも全画面になります。画面の上の端に触れると、小さなボタンが出ます。「メニュー」はよく使う操作、「戻る」で元の表示に戻ります。Escでブラウザの全画面を抜けたときは、「全画面」で戻せます。

オフラインで使う

一度開くと、ネットにつながっていなくても、このページで使えます(初めて開いたときに「次からは、ネットにつながっていなくても開けます」と出ます。保存できなかったと出たときは、「本体」の「オフライン用に保存し直す」で試し直せます)。iPhone・iPadでは、Safariの共有ボタンから「ホーム画面に追加」すると、アドレスバーのない画面で使えます。ほかのスマートフォンやパソコンでも、ブラウザのメニューの「ホーム画面に追加」や「インストール」で、アプリと同じように使えます。

保存とダウンロード

  • RAMの中身は機種ごとにこのブラウザに保存され、次に開いたときに戻ります。初期状態に戻すときは、本体の下の「本体」から「RAMを消して初期状態から始める」を選びます。
  • 書き出したプログラム、印字、画面の写しは、ダウンロードで受け取ります。
  • iPhoneとiPadのSafariは、7日間開かないサイトの保存を消すことがあります。ホーム画面に追加すると消えません。

ブラウザ版でできないこと

録画、ゲームパッド、実機のROMを使った実行は、パソコン版でできます。パソコン版はGitHubのsc61boxからインストールします。

How to use

An emulator of the SHARP pocket computers PC-1245, PC-1250, PC-1251, PC-1255, PC-1260, PC-1261, PC-1262 and PC-1350. It runs entirely in your browser and uses no ROM. BASIC is a ROM-less reimplementation, and some commands are not made yet.

Pressing keys

Click or tap the keys on the calculator. On a computer keyboard, letters, digits and symbols type as they are. Keys that only the pocket computer has are on these keys.

TabSHIFT
Option (Alt on Windows)DEF
F1–F4Mode switch

⌘/ (Ctrl/ on Windows) shows every key. Change the model at the top of the page. For the PC-1350, choose the RAM card there too.

Loading programs

  • Load and run the bundled programs from Programs below the calculator.
  • Load your own .bas and .hex files with Load file, or drop them on this page. They stay in the Programs list.
  • Load .bas, .hex and .wav files from other sites with a link to this page followed by ?load= and the file's URL. Add &run to run the program too (CLOAD and RUN for .wav). Only files on sites that allow loading from other sites (such as GitHub) can be loaded.
  • Copy program as a link in Programs makes a link that holds the BASIC program in RAM. Opening the link loads and runs the program.
  • Write and run machine code in the Workbench below the calculator.

Full screen

Full screen hides the bar at the top of the page and the buttons below the calculator, and fills the screen with the calculator alone. Browsers that support full screen also go full screen. Touch the top edge of the screen to show small buttons: Menu for common actions and Back to return to the normal view. If Esc takes the browser out of full screen, Full screen goes back to it.

Offline use

Once opened, this page works without a network connection (the first time you open it, a message tells you so; if it says the files could not be kept, try again with Keep for offline use again in Machine). On iPhone and iPad, choose Add to Home Screen from Safari's share button to use it without the address bar. On other phones and computers, Add to Home Screen or Install in the browser menu lets you use it like an app.

Saving and downloads

  • The RAM of each model is saved in this browser and comes back the next time you open the page. To start from the initial state, choose Erase RAM and start fresh in Machine below the calculator.
  • Exported programs, printouts and screenshots arrive as downloads.
  • Safari on iPhone and iPad may clear the saved data of a site you have not opened for 7 days. Add the page to the Home Screen to keep it.

Not in the browser version

Recording, gamepads and running a real ROM are in the desktop version. Install it from sc61box on GitHub.
